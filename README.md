## 合规第一步：实名注册（¡Muy Importante!）

　　这是和国内情况最不同的地方，也是最大的一道坎。危地马拉法律规定，所有SIM卡必须进行实名认证后才能正常使用通话和数据服务。

　　购买时，你需要出示护照原件。店员会帮你把信息录入系统。但注意！这通常只是第一步。激活后的一段时间内（可能几小时到一天），你可能需要拨打一个运营商指定的号码（如Claro是*888#）完成最终的验证流程。如果跳过这一步，你的卡很快就会被停机。我见过不止一个朋友在这里栽跟头。

## 搞定网络：APN设置与设备兼容

　　大多数新手机插卡即用，但偶尔也需要手动设置APN。这就像给手机一把正确的门钥匙。
　　如果发现有信号却无法上网，别慌，大概率是APN没配好。直接去设置里新建一个APN，对于Claro，名称和APN都填“internet”；Tigo则填“tigoweb”。保存并选中它，重启手机，通常就能解决。

　　设备兼容性方面，危地马拉主要使用4G LTE bands 2, 4, 5, 7。绝大多数国内带来的全网通手机都完美支持，这点可以放心。
